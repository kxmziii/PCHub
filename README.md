# PC Hub

โปรแกรมรวมเครื่องมือช่วยใช้คอม: เปิดแอพเป็นโหมด, ลบขยะ, ช่วยจัดการเซิร์ฟเวอร์ Discord และเครื่องมือเล็กๆ อื่นๆ

ทำด้วย C# + WPF (.NET 10)

## โครงสร้างโปรเจกต์

```
PCHub/
├─ PCHub.slnx              ไฟล์ solution (เปิดด้วย VS Code / Visual Studio)
└─ src/PCHub/
   ├─ App.xaml             จุดเริ่มต้นของโปรแกรม + ธีม
   ├─ MainWindow.xaml      หน้าต่างหลัก (เมนูซ้าย + หน้าเนื้อหา)
   ├─ Themes/Theme.xaml    สี ฟอนต์ ปุ่ม การ์ด (แก้ธีมทั้งโปรแกรมได้ที่ไฟล์นี้ไฟล์เดียว)
   ├─ Views/               หน้าแต่ละเมนู (โหมด, ลบขยะ, Discord, เครื่องมือ)
   ├─ Services/            ตัวทำงานจริง (เปิดแอพ, สแกน/ลบไฟล์, อ่านข้อมูล Discord)
   ├─ Helpers/             ตัวช่วยเล็กๆ (เช่น แถบหัวหน้าต่างสีมืด)
   ├─ Models/              โครงสร้างข้อมูล (โหมด, แอพ, ผลสแกน)
   └─ Assets/              ไอคอน รูปภาพ
      ├─ logo-source.png   โลโก้ต้นฉบับ (1024px มุมใส)
      ├─ app.ico           ไอคอนโปรแกรม (สร้างอัตโนมัติ)
      └─ logo.png          โลโก้ในเมนูซ้าย (สร้างอัตโนมัติ)
tools/
└─ make-icon.ps1           แปลงโลโก้เป็น app.ico + logo.png
```

## เปลี่ยนโลโก้

ใช้รูปสี่เหลี่ยมจัตุรัสที่มุมใส (PNG 1024px ขึ้นไป) แล้วรัน:

```bash
powershell -ExecutionPolicy Bypass -File tools/make-icon.ps1 -Source src/PCHub/Assets/logo-source.png
```

จากนั้น build ใหม่ ไอคอนจะเปลี่ยนทุกที่ (Desktop, Taskbar, Alt+Tab, หัวหน้าต่าง, เมนูซ้าย)

## ฟีเจอร์ที่วางแผนไว้

- [x] 🎮 คลังเกม: หาเกมจาก Steam / Epic / Riot / Start Menu อัตโนมัติ มีรูปปก กดเล่นได้เลย
- [x] ⚡ เซสชันเล่นเกม + Game Boost: ปิดแอพเบื้องหลัง สลับโหมดพลังงาน เปิด Discord จับเวลาเล่น แล้วคืนค่าเครื่องตอนเลิกเล่น
- [x] 💾 พื้นที่เกม: ดูว่าเกมไหนกินที่ และไม่ได้เล่นนานแล้ว
- [x] 🎁 เกมฟรีประจำสัปดาห์ (Epic แจกฟรี + Steam ลดราคาเป็นเงินบาท)
- [ ] 📦 ตัวติดตั้ง + อัปเดตอัตโนมัติ
- [x] 📶 เช็คปิงเซิร์ฟเวอร์เกม (สิงคโปร์ ฮ่องกง โตเกียว + ป้ายปิงที่เมนูซ้าย)
- [x] 📊 Gaming Wrapped (เดือนนี้ / เดือนที่แล้ว / 2 สัปดาห์จาก Steam) บันทึกหรือคัดลอกเป็นรูป 1080x1350
- [x] 🚀 โหมด / เปิดแอพ: เปิดหลายแอพพร้อมกันด้วยคลิกเดียว (คีย์ลัดทำในขั้นตั้งค่า)
- [x] 🧹 ลบขยะ: สแกนก่อน โชว์ขนาด แล้วค่อยยืนยันลบ
- [ ] 💬 Discord: วิเคราะห์ไฟล์ข้อมูลจาก Discord หาเซิร์ฟที่ไม่ได้ใช้ (ไม่ใช้ token / ไม่ผิดกฎ)
- [ ] 🛠️ เครื่องมือ: ดูแอพกินแรม, ตั้งเวลาปิดเครื่อง, จัดไฟล์ Downloads
- [ ] ⚙️ ตั้งค่า: เปิดพร้อม Windows, ย่อไว้มุมจอ

## ไฟล์ตั้งค่า

โหมดต่างๆ เก็บไว้ที่ `%APPDATA%\PCHub\settings.json` (ลบไฟล์นี้ = กลับไปใช้โหมดตั้งต้น)

## วิธีรัน

```bash
dotnet run --project src/PCHub
```

## สร้างไฟล์ .exe

```bash
dotnet publish src/PCHub -c Release -r win-x64 --self-contained false -o publish
```
