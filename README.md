# PC Hub

ผู้ช่วยเกมเมอร์ไทย: **กดทีเดียว เครื่องพร้อมเล่น** รวมเกมทุก launcher, เตรียมเครื่องก่อนเล่น, จับเวลาเล่น, ลบขยะ, เช็คปิง และสรุปการเล่นไว้แชร์

ทำด้วย C# + WPF (.NET 10)

## ฟีเจอร์

- [x] 🚓 FiveM Hub: เซิร์ฟไทยพร้อมจำนวนคนสด ปิง ติดดาว กดเข้าเซิร์ฟ ล้าง cache
- [x] 🎮 คลังเกม: หาเกมจาก Steam / Epic / Riot / Start Menu อัตโนมัติ มีรูปปก เวลาเล่น กดเล่นได้เลย
- [x] ⚡ เซสชันเล่นเกม + Game Boost: ปิดแอพเบื้องหลัง สลับโหมดพลังงาน เปิด Discord จับเวลาเล่น แล้วคืนค่าเครื่องตอนเลิกเล่น
- [x] 🎁 ของฟรี & ลดราคา: Epic แจกฟรี + Steam ลดราคาเป็นเงินบาท + เฝ้าราคาเกม (Wishlist / เพิ่มเอง)
- [x] 🔔 แจ้งเตือนที่มุมจอ: เกมที่เฝ้าลดราคา, Epic แจกฟรีใหม่, แพตช์ใหม่ของเกมที่เพิ่งเล่น
- [x] 📊 Gaming Wrapped: สรุปการเล่น บันทึกหรือคัดลอกเป็นรูป 1080x1350
- [x] 🚀 โหมด / เปิดแอพ: เปิดหลายแอพพร้อมกันด้วยคลิกเดียว
- [x] 🧹 ลบขยะ & 💾 พื้นที่เกม: สแกนก่อน ยืนยันก่อนลบ / ดูว่าเกมไหนกินที่และไม่ได้เล่นนาน
- [x] 📶 เช็คปิง: สิงคโปร์ ฮ่องกง โตเกียว + ป้ายปิงที่เมนูซ้าย + รายงานเน็ตหลังเล่น (กระตุกกี่ครั้ง เน็ตบ้านหรือเส้นทางไปเซิร์ฟ)
- [x] 📦 ตัวติดตั้ง + อัปเดตอัตโนมัติ (Velopack + GitHub Releases)
- [x] ✨ หน้าโหลดตอนเปิดโปรแกรม
- [ ] 💬 Discord: วิเคราะห์ไฟล์ข้อมูลจาก Discord หาเซิร์ฟที่ไม่ได้ใช้ (ไม่ใช้ token / ไม่ผิดกฎ)
- [ ] 🛠️ เครื่องมือเพิ่ม: ดูแอพกินแรม, ตั้งเวลาปิดเครื่อง, จัดไฟล์ Downloads
- [x] ⚙️ ทำงานเบื้องหลัง: ย่อไว้มุมจอ, เปิดพร้อม Windows, จับเวลาเล่นอัตโนมัติแม้เปิดเกมจาก launcher โดยตรง
- [ ] ⌨️ คีย์ลัด

**หลักความปลอดภัย:** ไม่ยุ่งกับตัวเกม (ไม่ inject / ไม่อ่านหน่วยความจำ) ไม่ลบไฟล์โดยไม่ถาม ถอนเกมผ่าน launcher เท่านั้น ไม่เก็บหรือส่งข้อมูลผู้ใช้

## โครงสร้างโปรเจกต์

```
PCHub/
├─ PCHub.slnx              ไฟล์ solution (เปิดด้วย VS Code / Visual Studio)
├─ dotnet-tools.json       เครื่องมือของโปรเจกต์ (vpk สำหรับสร้างตัวติดตั้ง)
├─ src/PCHub/
│  ├─ Program.cs           จุดเริ่มโปรแกรม (Velopack ทำงานก่อน แล้วค่อยเปิด WPF)
│  ├─ App.xaml             ธีม + เปิดหน้าต่างหลัก
│  ├─ MainWindow.xaml      หน้าต่างหลัก (เมนูซ้าย, การ์ดเซสชัน, ป้ายปิง)
│  ├─ Themes/Theme.xaml    สี ฟอนต์ ปุ่ม การ์ด (แก้ธีมทั้งโปรแกรมได้ที่ไฟล์นี้ไฟล์เดียว)
│  ├─ Views/               หน้าแต่ละเมนู
│  ├─ Services/            ตัวทำงานจริง (หาเกม, จับเวลา, Boost, ลบขยะ, ปิง, ดีล, อัปเดต)
│  ├─ Helpers/             ตัวช่วยเล็กๆ (อ่านไฟล์ Steam, จัดรูปแบบเวลา/ขนาด)
│  ├─ Models/              โครงสร้างข้อมูล
│  └─ Assets/              โลโก้และไอคอน
└─ tools/
   ├─ make-icon.ps1        แปลงโลโก้เป็น app.ico + logo.png
   └─ release.ps1          สร้างตัวติดตั้งสำหรับแจก
```

## ข้อมูลของผู้ใช้

เก็บไว้ที่ `%APPDATA%\PCHub\`
- `settings.json`: โหมด, เกมที่เพิ่มเอง/ซ่อน, ค่า Game Boost (ลบไฟล์นี้ = กลับไปใช้ค่าตั้งต้น)
- `playtime.json`: ประวัติการเล่น (ใช้ทำเวลาเล่นและ Gaming Wrapped)

## วิธีรัน (ตอนพัฒนา)

```bash
dotnet run --project src/PCHub
```

## ดาวน์โหลด

โหลด **PCHub-win-Setup.exe** จาก [หน้า Releases](https://github.com/kxmziii/PCHub/releases/latest) แล้วดับเบิลคลิกติดตั้ง
- ตอนเปิดครั้งแรกอาจเจอหน้าจอ "Windows protected your PC" เพราะยังไม่มีใบรับรอง ให้กด **More info → Run anyway**
- ลงครั้งเดียว หลังจากนั้น PC Hub จะอัปเดตเองเมื่อมีเวอร์ชันใหม่

## ปล่อยเวอร์ชันใหม่

1. เพิ่มเลข `<Version>` ใน `src/PCHub/PCHub.csproj` (เช่น 0.3.0 → 0.3.1)
2. commit และ push โค้ดขึ้น GitHub
3. รัน (สร้างตัวติดตั้ง + อัปโหลดขึ้น GitHub Releases):

```bash
powershell -ExecutionPolicy Bypass -File tools/release.ps1 -Publish
```

เครื่องที่ลง PC Hub ไว้จะเจอเวอร์ชันใหม่ตอนเปิดโปรแกรม โหลดเบื้องหลัง แล้วอัปเดตตอนปิดโปรแกรม

## เปลี่ยนโลโก้

ใช้รูปสี่เหลี่ยมจัตุรัสที่มุมใส (PNG 1024px ขึ้นไป) แล้วรัน:

```bash
powershell -ExecutionPolicy Bypass -File tools/make-icon.ps1 -Source src/PCHub/Assets/logo-source.png
```
